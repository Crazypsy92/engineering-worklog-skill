# Daily Worklog Template｜日报记录模板

> 用途：记录开工计划与结束结果。开工计划可以在早上或晚上填写；企业报工系统字段仍以系统要求为准。

## 基本信息

- 日期：YYYY-MM-DD
- 项目/工作类别：
- 报工阶段：开工计划 / 结束报工 / 完整日报

## 开工计划（早上或晚上均可）

### 任务详情（定义）

1. 对象＋具体动作＋数量/范围。
2. 对象＋具体动作＋数量/范围。

### 计划目标（定性）

一句话说明预期结果和可验收指标。

### 计划数量（定量）

2

### 单位

项

### 计划工时H

普通白班默认8；晚间/加班按实际计划填写，未知为待确认。

### 计划输出物

测试记录、结果数据、问题清单。

## 结束报工

### 完成结果

1. 完成具体工作，关键指标/结果，已完成100%。
2. 完成具体工作，关键指标/结果，已完成80%。

> 每条完成结果都必须单独标注“已完成XX%”。完成比例表示工作包执行进度，不代表测试通过率或最终任务成功率。

### 实际数量（定量）

按计划工作包的相同口径填写。

### 实际工时H

待确认

### 实际输出物

只填写真实生成或留存的记录、数据、报告或代码改动。

## 计划与实际差异

- 未完成/部分完成事项：
- 已报过、不重复报工的事项：
- 计划外新增事项：
- 阻塞原因：
- 后续动作：

## 口径核对

- [ ] 开工计划或结束报工阶段判断正确
- [ ] 任务与用户截图/原计划逐项对应
- [ ] 补报内容已核对，避免重复
- [ ] 任务描述简洁易懂，并保留关键数量指标
- [ ] 实际数量与计划数量采用相同计量口径
- [ ] 每条完成结果都单独标注已完成百分比
- [ ] 完成比例、测试通过率和任务成功率已区分
- [ ] 实际工时来自确认信息或可信记录
- [ ] 输出物确实已生成或已留存
